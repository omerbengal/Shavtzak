Where the admin sets a member's custom hours

Both options sit inside the existing "הערות לשיבוץ" dialog (right swipe on the row), so the row gets no new icon. The only difference is how the date is picked.

A

Plain date + time fields

Turn on "שעות מותאמות", get a "from" and a "to" field, each with a date and a time. They start filled with the event's normal assembly and end times, so you only change what's different.

B

Day chips + time fields

Same switch, but the date is chosen from chips: the day before, each event day and the day after (with "תאריך אחר…" for anything else). Faster for "only day 1", and harder to pick a wrong date by mistake.

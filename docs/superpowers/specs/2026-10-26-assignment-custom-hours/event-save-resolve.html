נשאר 1 לבחירה

My calls, shown above: "להזיז עם האירוע" moves the hours by the same number of days the event moved and keeps the clock times. When only the event's times changed, not its dates, that button is hidden. "לערוך…" opens the same date and time fields as in the notes dialog, inside this window. A choice that hits a constraint shows the warning but can still be saved, the same as assigning a constrained member today.

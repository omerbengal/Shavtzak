A new section in the duplication window that already exists ("בחירת שיבוצים לאירוע המשוכפל"). Nothing is copied unless the admin ticks it. Each copied hour moves by the same number of days as the new event.

ביטולצור אירוע משוכפל

My calls, shown above: the boxes start unticked, so copying is opt-in, with "סמן הכל" for speed. If a member is removed in the "קונפליקטי זמינות" section, their row here disappears. The availability-conflict section is worked out from each member's real hours: copied hours if ticked, the event's hours if not. The window also opens when the only reason is custom hours, with no conflicts at all.

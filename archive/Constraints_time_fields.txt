│                                                                              │
│ Context                                                                      │
│                                                                              │
│ Team members need to specify time ranges within their date constraints.      │
│ Currently, constraints only support date-level unavailability/availability.  │
│ A team member might be busy in the morning but free in the evening for an    │
│ event. This feature adds startTime and endTime fields to DateConstraint to   │
│ enable time-based conflict detection with event times (assemblyTime and      │
│ endTime).                                                                    │
│                                                                              │
│ Key User Requirement: When time fields are not specified (null), the         │
│ constraint applies to the entire day (backward compatible).                  │

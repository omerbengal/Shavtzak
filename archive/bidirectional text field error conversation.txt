⏺ I found the issue. This is a known Flutter bug with RTL text editing. The
  problem is that the TextFormField has textDirection: TextDirection.rtl set
  explicitly on the widget, while the entire modal is already wrapped in a
  Directionality(textDirection: TextDirection.rtl) widget (line 520-521).

  When textDirection is set directly on a TextField, it affects the internal
  cursor position calculations. With bidirectional text like "אירוע #1" (Hebrew
  + Latin characters), the cursor position mapping between visual and logical
  positions gets confused - so the cursor appears at one position visually but
  deletes from a different logical position.

  TextFormField and let it inherit from the parent Directionality widget, which
  handles cursor positioning correctly.

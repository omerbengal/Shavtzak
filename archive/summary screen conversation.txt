  // Checks FULL event duration with time-based constraints
  final isAvailable = member.isAvailableForEventWithTime(event);

  // Respects allowMultipleAssignments flag
  if (!member.allowMultipleAssignments && !isAvailable) {
    continue; // Filter out entirely
  }

  // Members with allowMultipleAssignments always available
  if (member.allowMultipleAssignments) {
    availableMembersMap[member.id] = member;
  }

  1. Changed availability check: isAvailableOn(event.startDate) →

    - Includes time-based constraints

    - Members with this flag set are ALWAYS available (even if they have

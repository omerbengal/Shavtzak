Proposed behavior

The share image includes event title/date, assignment groups, names, status chips if not confirmed, and numbered notes. Phone icons stay out of the image; if an alternate phone exists, it can be represented as a numbered note or small marker.

For very long note text, I’d cap each note at a fixed length and add “…” so one event does not create an unreadably tall image.

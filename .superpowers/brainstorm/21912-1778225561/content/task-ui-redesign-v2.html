משימות: redesigned UX direction

Mobile-first, RTL, dense operational UI. Uses status chips, grouped event sections, clear warnings, and task detail actions without turning this into a generic project-management board.

Design principles from ui-ux-pro-max
1

Flat, functional Material UI

No decorative effects. Use Shavtzak blue/orange, neutral surfaces, status chips, and compact cards.

2

Mobile-first task execution

User screen focuses on "what do I need to handle now" with no filters in V1.

3

Admin control without spreadsheet chaos

Admin gets private filters, event grouping, quick scanning, and safe actions.
